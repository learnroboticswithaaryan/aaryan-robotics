🚗 Obstacle Avoiding Car

Components

  • Arduino Uno
  • Ultrasonic Sensor
  • Motor Driver
  • Battery
  • DC Motors

Working

Sensor detects obstacle → car stops & turns → else moves forward.

Wiring

TRIG→9 ECHO→10 IN1→2 IN2→3 IN3→4 IN4→5

Code

#define echoPin 10

#define IN1 2
#define IN2 3
#define IN3 4
#define IN4 5

pinMode(trigPin,OUTPUT);

}
