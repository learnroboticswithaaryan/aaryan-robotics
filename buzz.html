🎯 Buzz Wire Game

🔧 Components

  • Battery (9V)
  • Buzzer
  • Metal Wire (maze)
  • Handle Loop Wire
  • Lamp / LED
  • Wooden Frame

🖼️ Circuit Diagram

Tip: Upload your image in the same repo and name it buzz.jpg

⚡ Working

The player moves a loop along the wire maze. If the loop touches the wire → circuit completes → buzzer sounds and light glows. If no touch → no sound.

🔌 Connection

Battery (+) → Wire Maze Wire Maze → Loop Loop → Buzzer → Battery (-) Lamp connected in parallel with buzzer

💡 Note

No Arduino needed — this is a simple electric circuit project.
