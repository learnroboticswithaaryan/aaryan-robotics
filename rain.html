🌧️ Rain Detector System

🔧 Components

  • Arduino Uno
  • Rain Sensor Module
  • Servo Motor / DC Motor
  • Motor Driver (optional)
  • Battery
  • Connecting Wires

⚡ Working

The rain sensor detects water drops. If rain is detected → motor rotates to pull clothes inside. If no rain → system stays idle.

🔌 Wiring

Rain Sensor → A0 Servo Signal → Pin 9 VCC → 5V GND → GND

💻 Full Code

#include 

Servo myServo;
int rainSensor = A0;

void setup(){
  myServo.attach(9);
  pinMode(rainSensor, INPUT);
}

void loop(){

  int value = analogRead(rainSensor);

  if(value < 500){
    // Rain detected
    myServo.write(90);
  }
  else{
    // No rain
    myServo.write(0);
  }

  delay(500);
}
